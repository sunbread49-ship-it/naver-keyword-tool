# 1페이지 확인 확장 프로그램 설치 (처음 한 번만)

1. 크롬 주소창에 `chrome://extensions` 를 입력합니다.
2. 예전에 설치한 "키워드 스카우트 - 내 상품 순위 조회"(v1)가 있으면 **삭제**합니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 눌러 이 `rank-extension` 폴더를 선택합니다.
5. 키워드 스카우트 대시보드를 새로고침하고 "📈 내 상품 순위"를 열면 **확장 연결됨**이 표시됩니다.

## 동작 방식
- 대시보드에서 상품의 **[1p 확인]**을 누르면 네이버 가격비교 검색 탭이 잠깐 열립니다.
- 그 탭에 이미 떠 있는 **1페이지 목록만** 읽어서 내 상품이 있는지 확인하고, 탭을 닫은 뒤 결과를 대시보드에 기록합니다.
- 누른 탭 한 개만 읽고, 백그라운드 연속 조회나 페이지 넘기기는 하지 않습니다.
- 사용자가 직접 연 네이버 검색 화면에서는 아무 일도 하지 않습니다.
- 네이버 접속 제한 화면이 뜨면 그 탭을 닫지 않고 남겨둡니다. 잠시 쉬었다가 다시 시도하세요.
