# 내 상품 순위 조회 확장 프로그램 설치 (처음 한 번만)

1. 이 `rank-extension` 폴더를 내 컴퓨터에 둡니다. 지우거나 옮기면 확장이 꺼지니, 고정된 위치에 두세요.
2. 크롬 주소창에 `chrome://extensions` 를 입력합니다.
3. 오른쪽 위 **개발자 모드**를 켭니다.
4. **압축해제된 확장 프로그램을 로드합니다**를 눌러 `rank-extension` 폴더를 선택합니다.
5. 키워드 스카우트 대시보드를 새로고침하면, "📈 내 상품 순위" 화면에 **확장 연결됨**이 표시됩니다.

## 사용법
- 키워드 표의 📦 버튼을 누르면 그 키워드가 "내 상품 순위" 목록에 들어갑니다. 목록에 직접 입력해서 추가할 수도 있습니다.
- **내 스토어명**을 한 번 입력해두면, 검색 결과에서 내 스토어 상품을 자동으로 찾습니다.
- 특정 상품만 추적하려면 그 키워드 줄에 상품 링크를 붙여넣습니다. 가격비교 목록에서 상품명을 우클릭한 뒤 "링크 주소 복사"한 것을 쓰면 됩니다.
- **순위 일괄 조회**를 누르면 백그라운드 탭에서 차례로 검색합니다. 키워드 하나에 약 5~20초가 걸립니다.

## 기준
- 네이버 랭킹순, 40개씩 보기, **광고 제외**
- 5페이지(200위)까지 찾고, 그 뒤는 "200위 밖"으로 표시합니다.
- 네이버 보안 확인(자동입력 방지)이 뜨면 조회가 멈추고 그 탭이 앞으로 나옵니다. 직접 풀면 자동으로 이어서 진행합니다.
- 하루 1~2번 정도만 돌리는 것을 권장합니다. 너무 자주 돌리면 보안 확인이 자주 뜰 수 있습니다.
